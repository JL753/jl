# 数据库重新初始化说明

## 问题原因
代码已更新为使用 SHA-256 哈希存储密码，但数据库中仍是旧的明文密码，导致登录失败。

## 解决方案

### 方法 1：重新运行初始化脚本（推荐）
```bash
mysql -u root -p smartprep < sql/init.sql
```

### 方法 2：仅更新密码字段
如果不想删除现有数据，可以只更新密码：

```sql
USE smartprep;

-- 将所有用户密码更新为 "123456" 的 SHA-256 哈希值
UPDATE sp_user SET password = '8d969eef6ecad3c29a3a629280e686cf0c3f5d5a86aff3ca12020c923adc6c92';
```

## 验证
更新后，使用以下账号登录测试：

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | 123456 | 管理员 |
| teacher | 123456 | 教师 |
| student | 123456 | 学生 |

## 注意事项
- 密码 "123456" 的 SHA-256 哈希值为：`8d969eef6ecad3c29a3a629280e686cf0c3f5d5a86aff3ca12020c923adc6c92`
- 所有新注册用户的密码会自动哈希存储
- 生产环境请务必设置强密码并配置环境变量
