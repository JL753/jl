## 2. 新用户 vs 已学习用户判断

调用 `apiAbilityLatest()`，如果返回 null 或全0 → 新用户。

| 区域 | 已学习用户 | 新用户 |
|------|-----------|--------|
| 六维横幅 | ECharts雷达图 + 6维分数条 + AI诊断 | "暂无线章数据" + [前往学习] |
| 第一张卡 | "继续上次学习"（蓝紫渐变） | "前往学习"（绿色，→/student/subjects） |
| AI路径 | 推荐路径时间线 | "完成课程后将规划路径"占位 |
| 快捷入口 | 自适应测验/今日挑战/学习报告（一致） | 同左 |

---

## 3. 数据源

- `apiAbilityLatest()` → ECharts 雷达图6维数据 + 右侧分数条 + AI诊断
- `apiStudentDashboard()` → 继续学习/周统计/AI路径
- `apiGamificationStreak()` → 连续签到天数
