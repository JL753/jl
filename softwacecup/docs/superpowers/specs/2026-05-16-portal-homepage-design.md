# 门户首页重设计规格

**日期**：2026-05-16
**类型**：前端页面重设计
**关联**：[[2026-05-16-zhiyu-refactor-design]] [[2026-05-16-zhiyu-frontend-design]]

---

## 1. 目标

重设计门户首页（`/`），融合可汗学院的叙事分区结构与登录状态自适应能力，保留知域的星图深色主题 + 液态玻璃组件 + 壁纸切换系统。

---

## 2. 设计约束

- **保留**：液态玻璃组件风格、壁纸切换系统、CSS 自定义属性（`--leleo-brightness` 等）
- **改造**：轨道动画（简化为中心圆环旋转，去标签圆点）、AI 搜索栏（融入 TopNavBar）
- **新增**：登录状态自适应布局、角色分流卡片、底部引导区
- **紧凑原则**：所有内容尽量在首屏内展示（无需滚动或极少滚动），Hero 高度克制、间距紧凑、学科网格最多展示 4-8 个学科

---

## 3. 页面分区

### 3.1 整体结构（未登录）

```
┌─────────────────────────────────────────────────────────┐
│  TopNavBar（Logo 知域 + 壁纸切换 + 通知 + 用户头像）      │
├─────────────────────────────────────────────────────────┤
│  ① Hero（左） + ② 角色分流卡（右侧纵向两张）              │
├─────────────────────────────────────────────────────────┤
│  ③ 核心内容：探索学科（4列液态玻璃卡片网格）               │
├─────────────────────────────────────────────────────────┤
│  ④ 底部引导：CTA + 登录链接                              │
└─────────────────────────────────────────────────────────┘
```

### 3.2 整体结构（已登录）

```
┌─────────────────────────────────────────────────────────┐
│  TopNavBar（同未登录）                                   │
├─────────────────────────────────────────────────────────┤
│  ① Hero（全宽自适应，② 消失）                            │
├─────────────────────────────────────────────────────────┤
│  ③ 核心内容：继续学习 + AI推荐（并排） + 探索学科网格      │
└─────────────────────────────────────────────────────────┘
```

---

## 4. ① Hero 区

### 4.1 未登录状态

布局：左侧文字 + CTA（占约 75%），右侧轨道动画装饰。

- **标题**："探索知识宇宙"（大号渐变文字，蓝→青，~52px）
- **副标题**："AI驱动的个性化学习平台"（灰色小字，letter-spacing: 2px）
- **主 CTA**：[开始学习] → 未登录弹出 LoginModal，回调跳转 `/student/dashboard`
- **次 CTA**：[了解知域] → 滚动到下方探索学科区
- **轨道动画**：只保留同心圆环旋转 + 中心"知"字，去标签圆点，慢速装饰旋转
- **材质**：Hero 卡片为液态玻璃大卡片

### 4.2 已登录状态

布局：左侧欢迎信息 + 快捷入口（全宽），右侧轨道动画。

- **欢迎语**："欢迎回来，{用户名} 👋"（大白字）
- **状态摘要**："已连续学习 N 天 · 掌握 N 个知识点"（一行小字）
- **快捷入口**：3 个按钮 —— [继续上次学习] / [浏览课程] / [知识星图]
  - 继续上次学习 → `/lessons/{lastLessonId}`
  - 浏览课程 → `/subjects`
  - 知识星图 → `/student/knowledge-map`
- **轨道动画**：同未登录

---

## 5. ② 角色分流区（仅未登录）

位于 Hero 右侧，两张液态玻璃窄卡纵向排列。

每张卡片内容：
- 角色名小字（"我是学生" / "我是教师"）
- 一个简洁按钮（"进入学习" / "进入教学"）

交互：
- 点击 → 弹出 LoginModal，对应角色账号，跳转 `/student/dashboard` 或 `/teacher/dashboard`
- 悬浮：边框微光（学生蓝 / 教师紫）
- 已登录：此区域不渲染，Hero 自适应全宽（带过渡动画 300ms）

---

## 6. ③ 核心内容区

### 6.1 未登录

- **标题**："探索学科"
- **内容**：4 列液态玻璃卡片网格，响应式缩为 2 列（平板）/ 1 列（手机）
- **每张卡片**：学科名称 + 课程数量，点击跳转 `/subjects/{id}`

### 6.2 已登录

上下两排：

**上排**（两张并排）：
- **左 — 继续学习**：上次学习的课程名 + 课时名 + 进度条（百分比）+ [继续] 按钮
- **右 — AI 为你推荐**：WebSearchAgent 推荐资源列表（标题 + 来源平台 + 时长）

**下排**（全宽）：
- 探索学科，同未登录的 4 列卡片网格

---

## 7. ④ 底部引导区（仅未登录）

- **标题**："准备好开始了吗？"
- **副标题**："加入知域，开启你的个性化学习之旅"
- **主按钮**："免费注册"（蓝青渐变，弹出 LoginModal）
- **次链接**："已有账号？登录"（灰色小字，弹出 LoginModal）
- 无独立卡片包裹，居中对齐，上下留白充裕（60px）

---

## 8. 路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | PortalHome | 门户首页，公开访问，登录状态自适应 |

移除原有的登录后强跳转逻辑，改为已登录用户也可浏览 `/`。

---

## 9. 数据依赖

| 区域 | API | 说明 |
|------|-----|------|
| Hero（已登录） | `GET /api/auth/me` | 用户名、连续学习天数、掌握知识点数 |
| 继续学习（已登录） | `GET /api/progress/latest` | 最近学习的课时 + 进度 |
| AI 推荐（已登录） | `POST /api/lessons/{id}/recommend-resources` | WebSearchAgent 推荐 |
| 探索学科（通用） | `GET /api/subjects` | 学科列表 + 课程数 |
| 快捷入口（已登录） | `GET /api/progress/latest` | 上次课时 ID |

---

## 10. 过渡动画

- Hero 宽度自适应：已登录/未登录切换时 300ms ease
- 角色分流卡出现/消失：fade 200ms + transform 位移
- 卡片悬浮：translateY(-2px) + 边框发光 200ms
- 页面切换：fade 300ms
