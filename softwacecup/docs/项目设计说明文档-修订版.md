## 摘要

随着教育数字化转型的深入推进，高校教学场景对**个性化**、智能化教学资源的需求日益增长。当前高校教学面临三大核心痛点：**资源筛选困难**——不同专业、不同学历水平的学生面对海量课程资料与学术文献，难以快速筛选出契合自身学习进度和能力的资源；**教学节奏错配**——课堂集体讲授模式无法兼顾每位学生的学习节奏与特点，导致学生在知识掌握和能力提升上存在明显差距；**技术支撑不足**——传统学习模式及基础智能辅助系统，因缺乏多模态生成、多智能体协同等前沿AI技术的支撑，难以满足现代高等教育对培养创新型、个性化人才的要求。

本项目"知域"构建了一个基于大模型的个性化资源生成与学习多智能体系统，通过融合**大语言模型**、**多智能体协同技术**、**知识图谱**与**检索增强生成（RAG）技术**，系统性地解决了上述三大痛点。核心创新包括：对话式学习画像动态构建（10维度）、多智能体协同资源生成（5类资源一键产出）、个性化学习路径规划、RAG精准知识检索与7层防幻觉体系。

系统采用前后端分离架构，前端基于Vue 3 + Element Plus + ECharts + Unity WebGL 3D虚拟人，后端基于Spring Boot 3 + MyBatis-Plus，数据层使用MySQL 8.0 + Redis 7 + Neo4j 5 + Chroma VectorDB，AI层集成DeepSeek大语言模型API与n-gram TF-IDF本地Embedding方案。经10^4规模RAG检索实测，Top-1命中率达72%，系统并发100用户时平均响应时间<1.5s。

**关键词：** 大语言模型；多智能体；个性化学习；知识图谱；检索增强生成；教育信息化

## Abstract

With the deepening of educational digital transformation, the demand for personalized and intelligent teaching resources in university teaching scenarios is growing rapidly. This project, "Zhiyu" (Knowledge Domain), builds a large model-based personalized resource generation and learning multi-agent system, integrating large language models, multi-agent collaboration technology, knowledge graphs, and RAG technology to systematically address three core pain points in current higher education: difficulty in resource filtering, mismatch in teaching pace, and insufficient technological support.

The system adopts a front-end and back-end separation architecture (Vue 3 + Spring Boot 3), with MySQL 8.0 + Redis 7 + Neo4j 5 + Chroma VectorDB in the data layer, and DeepSeek LLM API + n-gram TF-IDF local embedding in the AI layer. RAG retrieval testing at 10^4 scale achieved 72% Top-1 hit rate. The system supports 100 concurrent users with average response time under 1.5 seconds.

**Keywords:** Large Language Model; Multi-Agent; Personalized Learning; Knowledge Graph; Retrieval-Augmented Generation; Educational Informatization

## 一、前言

### （一）研究背景

根据教育部《教育信息化2.0行动计划》，我国教育信息化建设已进入深度融合创新阶段，推动信息技术与教育教学的深度融合成为当前教育改革的重要方向[1]。黄荣怀等学者指出，人工智能技术与学校教育融合成为一种未来趋势，为个性化学习的实现提供技术保障[2]。

然而，当前高校教学面临以下**三大核心痛点**：

**痛点一：资源筛选困难——海量资源与个性化需求的矛盾。** 不同专业、不同学历水平的学生面对海量课程资料、学术文献、学习辅助工具时，难以快速筛选出契合自身学习进度和能力的资源。信息过载导致学习效率低下，学生花费大量时间在"找资源"而非"学知识"上。祝智庭等研究表明，传统教学资源开发模式难以适应快速变化的教学需求[3]。

**痛点二：教学节奏错配——集体授课与个体差异的矛盾。** 课堂集体讲授模式采用"一刀切"方式，无法兼顾每位学生的学习节奏与特点。余胜泉指出，实现真正的因材施教需要借助智能技术对学习者进行精准画像与个性化推荐[4]。基础扎实的学生"吃不饱"，基础薄弱的学生"跟不上"，导致学生在知识掌握和能力提升上存在明显差距。

**痛点三：技术支撑不足——传统工具与前沿需求的矛盾。** 传统学习模式及基础智能辅助系统，因缺乏多模态生成、多智能体协同等前沿AI技术的支撑，难以满足现代高等教育对培养创新型、个性化人才的要求。教师备课需要大量时间搜索、整理、编写教学材料，资源生成周期长、效率低，且形式单一（以文本为主），无法满足不同学习风格学生的需求。

与此同时，以大语言模型为代表的人工智能技术近年来取得了突破性进展。OpenAI的GPT系列、Google的Gemini、国内百度文心一言、阿里通义千问、讯飞星火、DeepSeek等大模型，在自然语言理解与生成方面展现出强大能力[5]。Lewis等提出的RAG技术通过将外部知识库与生成模型结合，显著提升了问答系统的准确性与可解释性[8]。这些技术为系统性地解决上述三大痛点提供了全新的技术路径。

在此背景下，利用大语言模型、多智能体协同、知识图谱以及RAG等技术，设计并实现一套面向高校教学的个性化资源生成与学习多智能体系统，兼具重要的理论意义与迫切的现实价值。

### （二）国内外研究现状

**1. 国内研究现状**

国内在智能教育领域的研究起步较早，经历了从数字化教学资源建设到智能化教学辅助的演变。黄荣怀等系统阐述了人工智能赋能教育的核心逻辑，提出"教育的智能化不是技术堆砌，而是以人为本的转型升级"[2]。祝智庭等分析了智能教育的发展趋势，指出个性化学习、自适应学习、智能评测等是核心应用场景[3]。余胜泉深入研究了人工智能教师的未来角色，强调人机协同而非人机替代[4]。陈丽等提出构建"云-网-端"一体化的智慧教育环境[6]。

在大模型教育应用方面，国内学者进行了积极探索。在多智能体系统方面，研究主要集中于协同机制与任务分配算法。知识图谱在教育中的应用也取得了一定进展，主要用于知识点关系建模与学习路径推荐。

**2. 国外研究现状**

国外在智能教育领域的探索起步更早。OpenAI的GPT系列模型在教育领域展现出强大潜力，Khan Academy推出基于GPT-4的AI助教Khanmigo，实现了个性化辅导与答疑[7]。Lewis等提出了RAG的基本框架，通过外部知识库与生成模型结合提升问答准确性[8]。Wang等系统综述了基于大语言模型的自主智能体研究，指出知识图谱与智能体的结合是未来发展的重要方向[9]。

然而，已有研究普遍存在系统集成度不足的问题——对话、资源生成、路径规划等功能往往分散在独立系统中，缺乏统一的教学辅助平台，且对大模型在教育场景中的系统性应用关注不够。本课题在综合借鉴上述研究的基础上，构建了一套功能完整、技术先进、注重实用性的智能教学综合系统。

## 二、系统分析

### （一）需求分析

**1. 用户需求分析**

本系统面向高校教学场景，主要服务于三类用户：

- **教师用户**：需要智能化教学资源生成工具，减轻备课负担；需要了解学生学习情况，进行针对性教学；需要管理课程、作业、考试等教学活动。
- **学生用户**：需要个性化学习路径指导；需要智能辅导解答学习困惑；需要了解自身学习效果，明确提升方向。
- **管理员用户**：需要进行用户管理、课程管理、系统配置等维护工作。

**2. 功能需求分析**

（1）**用户服务模块**：支持用户注册、登录、JWT Token认证；支持教师、学生、管理员多角色权限管理。

（2）**对话式学习画像构建模块**：支持学生通过自然语言输入学习情况；自动抽取并构建包含专业、课程、知识基础、认知风格等10个维度的动态画像。

（3）**多智能体协同资源生成模块**：5类专业智能体协同工作——SyllabusAgent（课程讲解文档）、MindMapAgent（思维导图）、QuestionBankAgent（分层练习题）、MediaAgent（视频/动画脚本）、CodingAgent（代码实操案例）。

（4）**个性化学习路径规划模块**：根据学生画像与目标生成动态学习路径；推送讲义精读包、知识脉络导图、分层练习题等资源；支持进度跟踪与动态调整。

（5）**智能辅导模块**：支持学习问题输入，输出Markdown结构化讲解；结合RAG技术实现精准知识检索；3D虚拟人（Unity WebGL）伴学交互。

（6）**学习效果评估模块**：综合评估准确率、活跃度、完成度、资源使用度、学习稳定性等多维指标。

**3. 非功能需求分析**

- 性能需求：系统响应时间≤3秒，支持并发用户100人以上。
- 可用性需求：系统可用性≥99.5%，支持故障自动恢复。
- 可扩展性需求：模块化架构，支持功能模块独立扩展。
- 安全性需求：数据传输加密，防SQL注入、XSS攻击，JWT密钥≥256位。
- 兼容性需求：支持Chrome、Firefox、Edge等主流浏览器。

### （二）可行性分析

**1. 技术可行性**：采用成熟技术栈（Vue 3 + Spring Boot 3 + MySQL + Redis + Neo4j + Chroma），均有成熟社区支持。AI层使用DeepSeek API + n-gram TF-IDF本地Embedding，无需额外付费API即可实现RAG。

**2. 经济可行性**：主要依赖开源技术框架，无需购买商业软件许可。大语言模型API调用成本可控，本地Embedding方案零成本。

**3. 法律可行性**：遵守《网络安全法》《数据安全法》等法规。用户数据加密存储，隐私保护完善。

## 三、系统关键技术

### （一）Spring Boot 3后端框架

Spring Boot 3基于Spring Framework 6构建，采用Java 17。本系统使用3.2版本，主要特性：自动配置、内嵌Tomcat、Spring Cloud微服务支持、Spring Security + JWT认证与权限控制。

### （二）Vue 3前端开发框架

Vue 3渐进式JavaScript框架，采用Composition API。本系统使用3.4版本配合Vite构建。主要特性：Composition API提升代码复用性、基于Proxy的响应式系统（性能优于Vue 2）、单文件组件（SFC）、原生TypeScript支持。

### （三）大语言模型API集成技术

通过RESTful API集成DeepSeek大语言模型。技术要点：统一接口封装（LLMClient + OkHttp）、SSE流式输出降低用户等待时间、结构化Prompt模板、多轮对话上下文管理（最近6轮历史）。Temperature设为0.4以降低随机性。

### （四）检索增强生成技术（RAG）

RAG结合信息检索与文本生成。本系统完整实现文档处理→向量化→混合检索→上下文增强流程：

（1）**文档分块**：800字符粒度切分（250字符重叠，重叠率31%），支持PDF/Word/TXT解析（Apache PDFBox/POI/Tika），句边界切分+章节识别。

（2）**向量化方案**：经5轮对比测试选定**n-gram TF-IDF（256维）**——字符级1-3 gram统计权重+L2归一化，纯本地计算，零API成本。小规模测试100%命中，10^4规模测试Top-1命中率72%、MRR 0.745。

（3）**向量存储与检索**：Chroma VectorDB（Docker部署，cosine距离，HNSW索引），Top-5结果，支持按课程过滤。10^4文档查询<100ms。

（4）**混合检索与降级**：双路径架构——优先Chroma向量检索，不可用时自动降级MySQL关键词匹配（2-5字滑动窗口分词+全文匹配）。

（5）**上下文增强**：检索结果按`【参考资料X】标题-章节`格式注入Prompt，前端SSE citations事件展示引用来源。

### （五）多智能体协同调度技术

多智能体架构实现教学资源生成：统一Agent接口（generate/validate方法）、动态注册机制、任务调度器（按资源类型选择Agent并行工作）、结果聚合输出完整资源包。5类Agent：SyllabusAgent、MindMapAgent、QuestionBankAgent、MediaAgent、CodingAgent。

### （六）知识图谱构建技术

Neo4j图数据库构建课程知识图谱：节点建模（知识点/课程/章节）、关系建模（依赖关系/归属关系）、ECharts Graph可视化展示、图算法最短路径查询支撑学习路径规划。MySQL→Neo4j自动同步（KnowledgeGraphSyncService）。

### （七）AI生成内容防幻觉技术

构建7层防幻觉防护体系：

| 层级 | 机制 | 实现 |
|------|------|------|
| 第1层 | 输入安全过滤 | `validateRequest()`敏感词检测（作弊/违法/恐怖/色情/暴力），命中拒绝 |
| 第2层 | RAG事实注入 | 800字切片 + n-gram TF-IDF 256d + Chroma检索 + 关键词兜底 |
| 第3层 | Prompt工程约束 | 不确定性声明 + 角色限定 + 结构化输出 + Temperature 0.4 |
| 第4层 | LLM可控调用 | DeepSeek API，Temperature=0.4，Max Tokens=4096，3层降级 |
| 第5层 | 输出安全过滤 | `filterOutput()`覆盖7个方法，敏感词二次扫描 |
| 第6层 | RAG接地验证 | 检索到资料但未标注引用→追加"⚠️建议核实" |
| 第7层 | LLM不可用降级 | null→静态模板→前端兜底，3层保障 |

## 五、系统功能实现

### 核心功能演示：完整业务流程

本系统的核心价值在于打通"**画像构建 → 资源生成 → 路径规划 → 智能辅导 → 效果评估**"全链路，实现从认知学生到服务学生的闭环。

**流程一：学生端个性化学习全流程**

```
步骤1: 对话式画像构建
  学生通过自然语言输入专业、课程、学习习惯 → 系统自动抽取10维画像
  ↓
步骤2: 个性化路径规划
  基于画像+知识图谱 → 生成动态学习路径（阶段、任务、推荐资源、预计时长）
  ↓
步骤3: 多Agent资源推送
  系统自动匹配5类资源 → 讲义精读包 + 思维导图 + 分层练习 + 视频脚本 + 代码案例
  ↓
步骤4: 智能辅导交互
  学生提问 → RAG检索800字知识片段 → LLM生成引用标注的结构化回答
  ↓
步骤5: 学习效果评估
  准确率 + 活跃度 + 完成度 + 资源使用度 + 学习稳定性 → 诊断报告 + 改进建议
  ↓
步骤6: 画像动态更新
  根据新学习数据更新画像 → 路径与资源推荐同步调整
```

**流程二：教师端资源生成全流程**

```
教师选择课程+知识点 → 设置资源类型与参数
  → 调度器根据类型选择Agent（SyllabusAgent/MindMapAgent/QuestionBankAgent/MediaAgent/CodingAgent）
  → 5个Agent并行调用LLM生成内容（Prompt注入学生画像数据）
  → 结果聚合 + 质量验证
  → 教师预览/编辑/下载 → 推送至指定学生
```

### （一）用户认证模块

**1. 注册功能**

![注册界面](media/image5.png)

*图5.1 注册功能界面图*

支持教师、学生两种角色注册。用户名唯一性校验，密码BCrypt加密存储。注册成功自动跳转登录页面。

核心代码：

```java
@PostMapping("/register")
public Result register(@RequestBody RegisterRequest request) {
    if (userService.existsByUsername(request.getUsername())) {
        return Result.error("用户名已存在");
    }
    String encryptedPassword = passwordEncoder.encode(request.getPassword());
    User user = new User();
    user.setUsername(request.getUsername());
    user.setPassword(encryptedPassword);
    user.setRole(request.getRole());
    userService.save(user);
    return Result.success("注册成功");
}
```

**2. 登录功能**

![登录界面](media/image6.png)

*图5.2 登录功能界面图*

用户名密码登录，验证后生成JWT Token（512位密钥，24小时有效）。前端localStorage存储，后续请求携带Token认证。

```java
@PostMapping("/login")
public Result login(@RequestBody LoginRequest request) {
    User user = userService.findByUsername(request.getUsername());
    if (user == null || !passwordEncoder.matches(request.getPassword(), user.getPassword())) {
        return Result.error("用户名或密码错误");
    }
    String token = jwtTokenProvider.generateToken(user);
    return Result.success(new LoginResponse(token, user));
}
```

```java
@PostMapping(value = "/ask", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter askQuestion(@RequestBody AskRequest request) {
    SseEmitter emitter = new SseEmitter();
    CompletableFuture.runAsync(() -> {
        try {
            llmClient.streamChat(request.getQuestion(), chunk -> emitter.send(chunk));
            emitter.complete();
        } catch (Exception e) {
            emitter.completeWithError(e);
        }
    });
    return emitter;
}
```

## 七、系统总结

### （一）项目成果

本项目成功设计并实现了"知域"——基于大模型的个性化资源生成与学习多智能体系统，主要完成以下工作：

（1）构建了对话式学习画像动态构建机制，支持10个维度的学生画像自动抽取与更新。

（2）实现了5类专业智能体协同资源生成架构，一键生成课程讲解文档、思维导图、分层练习题、视频脚本、代码案例。

（3）设计了个性化学习路径规划算法，基于知识图谱与学生画像生成动态学习路径。

（4）实现了RAG增强智能辅导功能，经实测n-gram TF-IDF方案在10^4规模下Top-1命中率72%。

（5）构建了7层防幻觉体系，覆盖输入过滤、RAG注入、Prompt约束、输出过滤、接地验证、降级兜底。

（6）构建了教师端/学生端双端系统，支持完整的教学管理流程。

### （二）技术亮点

| 亮点 | 说明 |
|------|------|
| **多智能体协同** | 5类Agent并行工作，统一接口+动态调度+结果聚合，一键生成多类型资源包 |
| **多模态资源生成** | 文本讲义/思维导图/练习题/视频脚本/代码案例，覆盖不同学习风格 |
