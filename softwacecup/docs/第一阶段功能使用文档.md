## 🎯 功能一：左右分屏伴学界面

### 功能描述
实现了一个沉浸式的左右分屏学习界面，左侧展示学习资源（PDF/视频/文档），右侧提供AI助手实时对话。

### 访问路径
```
http://localhost:5173/student/companion
```

### 核心特性

#### 1. 左侧资源预览区
- **PDF预览**：支持PDF文档在线预览，带翻页控制
- **视频播放**：支持视频资源播放
- **文档展示**：支持Markdown格式文档渲染

#### 2. 拖拽分隔条
- 鼠标拖拽中间分隔条可调整左右面板宽度
- 支持触摸设备拖拽
- 实时响应，流畅交互

#### 3. 右侧AI助手对话区
- **流式输出**：打字机效果，实时显示AI回复
- **Markdown渲染**：支持标题、列表、表格、引用等
- **LaTeX公式**：支持行内公式 `$...$` 和块级公式 `$$...$$`
- **代码高亮**：支持多种编程语言语法高亮
- **消息历史**：保留完整对话记录
- **快捷模板**：一键插入常用问题模板

### 使用方法

#### 步骤1：登录系统
```
用户名: student
密码: 123456
```

#### 步骤2：访问分屏学习页面
导航至：学生端 → 伴学助手 (或直接访问 `/student/companion`)

#### 步骤3：上传学习资源
1. 点击左侧面板的"上传PDF"/"上传视频"/"上传文档"按钮
2. 选择本地文件上传（当前为演示模式，可使用示例资源）

#### 步骤4：与AI助手对话
1. 在右侧输入框输入问题
2. 点击发送按钮或按 `Ctrl+Enter` / `Cmd+Enter` 发送
3. AI将以流式方式返回答案

#### 步骤5：使用快捷模板
点击输入框上方的快捷按钮：
- 💡 解释概念
- 📋 总结要点
- 🌰 举例说明
- ✍️ 生成练习

```javascript
import { openTutorSSE } from '@/api/sse'
import { renderMarkdown } from '@/utils/markdown'

const sendMessage = async () => {
  let markdownBuffer = ''
  const aiMessage = { role: 'assistant', html: '', text: '' }
  messages.value.push(aiMessage)

  openTutorSSE({ question: inputMessage.value }, {
    onDelta(chunk) {
      markdownBuffer += chunk
      aiMessage.text = markdownBuffer

      scrollToBottom()

    onDone() {
      isLoading.value = false
    }
```

**拖拽分隔条**：
```javascript
const startDrag = (e) => {
  isDragging.value = true
  const startX = e.clientX || e.touches[0].clientX
  const startWidth = leftWidth.value

  const onMove = (moveEvent) => {
    const currentX = moveEvent.clientX || moveEvent.touches[0].clientX
    const deltaX = currentX - startX
    const containerWidth = document.querySelector('.split-pane-study').offsetWidth
    const deltaPercent = (deltaX / containerWidth) * 100
    leftWidth.value = Math.max(20, Math.min(80, startWidth + deltaPercent))
  }

  document.addEventListener('mousemove', onMove)
  document.addEventListener('touchmove', onMove)
}
```

#### 核心函数
```javascript
import { marked } from 'marked'
import DOMPurify from 'dompurify'

export function renderMarkdown(text) {
  // 1. 处理LaTeX公式
  text = processLatex(text)

  // 2. Markdown转HTML
  let html = marked.parse(text)

  // 3. XSS防护
  html = DOMPurify.sanitize(html)

  return html
}
```

#### 代码高亮实现
```javascript
function highlightCode(code, language) {
  const keywords = {
    javascript: ['const', 'let', 'var', 'function', 'return', 'if', 'else'],
    python: ['def', 'class', 'import', 'return', 'if', 'elif', 'else'],
    java: ['public', 'private', 'class', 'void', 'return', 'if', 'else']
  }

  let highlighted = escapeHtml(code)

  keywords[language]?.forEach(keyword => {
    const regex = new RegExp(`\\b(${keyword})\\b`, 'g')
    highlighted = highlighted.replace(regex, '<span class="keyword">$1</span>')
  })

  return highlighted
}
```

## 📝 注意事项

### 1. 依赖安装问题
如果遇到npm安装失败，请尝试：
```bash
# 清理缓存
npm cache clean --force

# 删除node_modules重新安装
rm -rf node_modules package-lock.json
npm install
```

### 2. LaTeX渲染增强
当前使用简化版LaTeX渲染，如需完整支持，可安装KaTeX：
```bash
npm install katex
```

然后在 `markdown.js` 中启用KaTeX渲染。

```bash
npm install highlight.js
```
