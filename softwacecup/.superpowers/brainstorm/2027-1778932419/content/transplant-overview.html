后端适配方案

复用目标项目已有能力

  • 讯飞 LLM → Java AgentController 新增加 /api/agent/chat 端点
  • 讯飞 STT → 新增 /api/agent/stt 语音识别端点
  • 讯飞 TTS → 新增 /api/agent/tts 语音合成端点
  • 前端 api/index.js 新增对应的 API 函数

需要注意的问题

  • Unity WebGL 文件较大 (~20MB)，需关注加载速度
  • 麦克风权限需要 HTTPS 或 localhost
  • 讯飞 STT/TTS API 配额需确认
  • Unity → Vue 通信桥接需要全局函数适配
